Installation instructions:
-----------------------

 1. Run the installation of Adobe XD (file autoplay.exe), and normally continue
    keep it up to a successful end.

 2. After closing the program installer window, in automatic mode
    the healing mechanism starts. Just wait for the message to appear
    "Cracking complete. Enjoy!".
    ATTENTION: If the message does not appear for a long time, open the "Dispatcher
    tasks" (Task Manager) and end the "Adobe IPC Broker" process.

 3. Enjoy the opportunity to use the product without access to the network!

Инструкция по установке:
------------------------

 1. Запустите установку Adobe XD (файл autoplay.exe), и штатно продол-
    жайте ее вплоть до успешного окончания.

 2. После закрытия окна установщика программы, в автоматическом режиме
    стартует  механизм  лечения.  Просто дождитесь появления сообщения
    "Cracking complete. Enjoy!".
    ВНИМАНИЕ:  Если сообщение долго не появляется, откройте "Диспетчер
    задач" (Task Manager) и завершите процесс "Adobe IPC Broker".

 3. Наслаждайтесь возможностью использовать продукт без доступа в сеть!
