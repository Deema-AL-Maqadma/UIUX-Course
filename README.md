# 🎨 UI/UX Course – Repository

This repository contains all materials, assignments, practical labs, and the final project from the **UI/UX Design** course.  
It combines theoretical foundations with practical implementations using **Adobe XD**, **Balsamiq**, and **Figma**.

---

## 📚 Course Content
During the course I learned and applied the following topics:

- Fundamentals of UI/UX Design  
- Wireframing with **Balsamiq**  
- Prototyping with **Adobe XD**  
- High-fidelity design and mockups with **Figma**  
- Creating **User Persona** and **User Flow**  
- Designing and presenting a complete mobile app project  

---

## 📂 Repository Structure
The repository is organized as follows:

- **Adobe_XD/**  
  Contains early prototypes and design drafts.  

- **Assignments/**  
  Includes course assignments and practical exercises.  

- **UI,UX/**  
  Practical labs and exercises on wireframing and prototyping.  

- **UIUX_Final_Project/**  
  Complete implementation of the **Coffee Ordering App** project, including persona, user flow, wireframes, final design, and mockup presentation.  

---

## 🚀 Final Project – Coffee Ordering App
I implemented a **Coffee Ordering App** as the final project.  
The project demonstrates the full UI/UX design process:
- Defined a **User Persona** (Deema, 20-year-old student who loves coffee and fast service)  
- Designed a **User Flow** to map the journey from login to order tracking  
- Created **Wireframes** using Balsamiq  
- Built the **Final Design** on Figma with a warm beige and brown color palette  
- Prepared a **Mockup Presentation** showcasing the app’s main screens
